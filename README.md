# tam-km-truong.github.io

Personal landing page for **Minh Tam Truong Khac**, built with modern vanilla HTML5, CSS, and JavaScript.

## Features

- ⚡ **Zero-Build, Lightweight**: Pure HTML, CSS, and vanilla JS. Instant deployment via GitHub Pages.
- 🌓 **Dark & Light Mode**: Automatic system preference detection with manual toggle and `localStorage` persistence.
- 📱 **Fully Responsive**: Mobile-first layout with fluid typography and card grids.
- 🎯 **Versatile Positioning**: Highlights the intersection of **PhD Research**, **Software Engineering**, and **Product Management**.

## Local Preview

You can preview the page locally using Python's built-in web server:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.

## Deployment to GitHub Pages

1. Commit and push changes to GitHub:
   ```bash
   git add .
   git commit -m "feat: barebone landing page"
   git push origin main
   ```
2. In your repository settings on GitHub, navigate to **Pages** and ensure the source branch is set to `main` (root directory `/`).
3. Your site will automatically go live at `https://tam-km-truong.github.io/`.
